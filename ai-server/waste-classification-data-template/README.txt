TEMPLATE DATA KLASIFIKASI ECO SCAN

Struktur folder:
  train/ = foto untuk melatih model
  val/   = foto untuk validasi selama training
  test/  = foto untuk evaluasi akhir (opsional)

Kelas: organik, anorganik, b3, residu.
Taruh file JPG/JPEG/PNG langsung di folder kelas yang sesuai. Hapus file .gitkeep setelah folder diisi.

Gunakan satu objek sampah yang terlihat jelas per foto. Jangan menaruh foto yang sama atau foto nyaris sama di train, val, dan test. Beri label sesuai jenis sampah yang benar.

Setelah folder diisi, ZIP kembali seluruh folder waste-classification-data-template dan kirim ZIP tersebut. Template ini belum berisi foto training.
